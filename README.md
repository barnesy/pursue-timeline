# Off Nominal

An interactive timeline + map of declassified anomaly data — UAP cases, nuclear
weapons tests and incidents, nuclear-physics milestones, and the CIA Stargate
program — with a physically grounded 3D nuclear-blast visualization and a
"collect & correlate" workflow for finding cross-dataset connections.

## Highlights

- **Six datasets, one timeline + world map.** Filter by dataset, agency, media,
  yield, altitude, and device. Co-located/same-day events cluster with counts
  (like the map) and expand into a shared selection menu.
- **3D blast visualization** (MapLibre GL) — geodesic damage rings drawn as real
  map geometry over streets / satellite / 3D terrain / 3D buildings, with a
  physically timed detonation animation (bomber → flash → fireball → mushroom
  cloud) driven by Glasstone-Dolan + Sedov-Taylor blast physics
  (`src/blastPhysics.ts`).
- **Cases — collect & correlate.** Add any case to a working set (persisted to
  `localStorage`); the header counter opens a combined view that lays the cases
  out side by side with full synopses, a fit-to-all mini-map + timeline, and
  live proximity correlations (km + years) from `src/proximity.ts`.

## Develop

```bash
npm install
npm run dev      # sync data → public/, then Vite dev server (http://localhost:5173)
npm run build    # type-check + production build to dist/
npm run preview  # preview the production build
```

The 3D map is code-split, so it only downloads when you open it.

## Data

Source data lives in `data/` and is copied to `public/` by `npm run sync-data`
(run automatically by `dev`/`build`). Datasets are generated by scripts in
`scripts/` (e.g. `npm run build-nuclear-physics`, `npm run build-uap-catalog`)
from sources in `data/raw/`. Provenance and per-record source links are baked
into each dataset (SIPRI, Wikipedia, National Archives, AARO, SCU, and others).

## Tech

React + TypeScript + Vite + MUI · D3 (scales/geo) for the timeline & world map ·
MapLibre GL + @turf for the 3D blast map · `useSyncExternalStore` for the Cases
collection. Dataset registry in `src/datasets.ts`.
